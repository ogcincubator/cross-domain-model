## Description

## OGC Cross Domain Semantic Model

This model is a "closure" of the set of canonical ontologies published by or recognised through usage in other OGC ontologies.

It represents the "baseline" for semantic interoperability within OGC and across other international standards environments.

Note that profiles specific to geography may be present to constrain usage of some ontologies.
